# GTO 引擎快速参考

## 核心公式

### 1. 最优虚张比例 (Optimal Bluff Ratio)
```
α = 下注额 / (底池 + 下注额)
最优虚张比例 = α / (1 - α)
```

**示例：**
- 下注 50% 底池：α = 0.33，虚张比例 = 0.5:1
- 下注 66% 底池：α = 0.4，虚张比例 = 0.67:1
- 下注 100% 底池：α = 0.5，虚张比例 = 1:1

### 2. MDF (最小防守频率)
```
MDF = 1 - α = 1 - (下注额 / (底池 + 下注额))
```

**速查表：**
| 下注尺度 | MDF | 弃牌率 |
|---------|-----|--------|
| 25% pot | 80% | 20% |
| 33% pot | 75% | 25% |
| 50% pot | 67% | 33% |
| 66% pot | 60% | 40% |
| 75% pot | 57% | 43% |
| 100% pot | 50% | 50% |
| 150% pot | 40% | 60% |
| 200% pot | 33% | 67% |

### 3. 盈亏平衡点 (Break-even Equity)
```
盈亏平衡点 = 下注额 / (底池 + 下注额)
```

### 4. SPR (Stack-to-Pot Ratio)
```
SPR = 有效筹码 / 底池
```

**SPR 策略：**
- SPR < 3：更多全压，减少虚张
- SPR 3-8：标准策略
- SPR > 8：更多深筹码策略，增加虚张

## 下注尺度指南

### 阻断下注 (Block Bet)
- **尺度：** 25-40% 底池
- **场景：** 河牌中等摊牌价值，失位
- **目的：** 保护底池，防止对手大额下注

### 小额下注 (Small Bet)
- **尺度：** 33-40% 底池
- **场景：** 融合范围，湿牌面
- **目的：** 保持范围平衡，获取信息

### 中等下注 (Medium Bet)
- **尺度：** 50-66% 底池
- **场景：** 标准持续下注
- **目的：** 平衡价值和虚张

### 大额下注 (Large Bet)
- **尺度：** 75-100% 底池
- **场景：** 强牌，极化范围
- **目的：** 最大化价值

### 超水下注 (Overbet)
- **尺度：** 125-200% 底池
- **场景：** 坚果牌，干燥牌面，对子牌面
- **目的：** 极化范围，最大化价值

## Check-raise 频率

### 按手牌强度
| 手牌强度 | Check-raise 频率 |
|---------|-----------------|
| 坚果牌 | 35% |
| 强牌 | 25% |
| 中等牌 | 12% |
| 弱牌 | 5% |
| 虚张 | 8% |

### 按位置调整
- **BB：** +30% 频率
- **SB：** +10% 频率
- **其他位置：** -15% 频率

### Check-raise 尺度
- **标准：** 2.5x 对手下注
- **坚果牌：** 3.0x 对手下注
- **虚张：** 2.2x 对手下注

## 剥削策略（无历史数据）

### 识别对手类型

#### 过度弃牌 (Overfolding)
- **特征：** 弃牌率 > 70%
- **剥削：** 增加虚张频率 +20-30%
- **下注尺度：** 使用小额下注诱导弃牌

#### 过度跟注 (Overcalling)
- **特征：** 弃牌率 < 40%，check-raise 频率低
- **剥削：** 减少虚张 -15-25%，增加价值下注
- **下注尺度：** 使用大额下注

#### 被动型 (Passive)
- **特征：** 侵略因子 < 1.5
- **剥削：** 更薄的价值下注，减少 check-back
- **下注尺度：** 中等到大额

#### 过度激进 (Overaggressive)
- **特征：** 侵略因子 > 3.5
- **剥削：** 更多抓虚张跟注，设置陷阱
- **下注尺度：** 让对手主动下注

## 牌面结构调整

### 湿度 (Wetness)
- **非常湿 (>0.7)：** 增加下注频率 +15%，增加 check-raise +20%
- **湿 (0.5-0.7)：** 标准策略
- **中等 (0.3-0.5)：** 标准策略
- **干 (< 0.3)：** 减少下注频率 -10%，考虑超水下注

### 对子牌面
- **调整：** 虚张频率 -15%，超水下注机会 +增加
- **原因：** 范围优势更明显

### 同花/顺子可能
- **调整：** 增加 check-raise +30%，增加下注尺度
- **原因：** 更多半虚张机会

## 位置调整

### 有位置 (BTN, CO)
- **下注频率：** +10-20%
- **虚张频率：** +15-20%
- **下注尺度：** 更灵活，可以使用更大尺度

### 失位 (BB, SB)
- **下注频率：** -5-10%
- **Check-raise：** +20-30%
- **阻断下注：** 更频繁使用

## 实战决策流程

### 1. 面对下注时
```
1. 计算 MDF
2. 评估手牌权益
3. 如果权益 >= MDF：
   - 考虑 check-raise（10-25% 频率）
   - 否则跟注
4. 如果权益 < MDF：
   - 弃牌
```

### 2. 主动下注时
```
1. 计算 SPR
2. 确定手牌强度
3. 选择下注尺度：
   - 坚果牌：考虑超水下注
   - 强牌：大额下注 (75-100%)
   - 中等牌：中等下注 (50-66%)
   - 弱牌/虚张：根据对手调整
4. 计算虚张比例
5. 执行混合策略
```

### 3. 剥削调整
```
1. 观察对手倾向（或推断）
2. 识别剥削机会
3. 调整频率：
   - 过度弃牌：+虚张
   - 过度跟注：-虚张，+价值
   - 被动：+薄价值
   - 激进：+抓虚张
```

## 常见错误

### ❌ 避免
1. **固定下注尺度** - 应该根据情况调整
2. **忽略 MDF** - 导致被无限虚张
3. **不平衡虚张** - 要么虚张太多，要么太少
4. **忽略位置** - 位置是最重要的因素之一
5. **过度剥削** - 在没有足够信息时偏离 GTO 太多

### ✅ 正确做法
1. **使用混合策略** - 不要总是做同样的动作
2. **平衡范围** - 保持价值和虚张的正确比例
3. **根据牌面调整** - 湿牌面和干牌面策略不同
4. **利用位置优势** - 有位置时更激进
5. **渐进式剥削** - 先从小调整开始

## 代码使用示例

```typescript
import { GTOEngine } from '@renderer/common/poker/gto';

const engine = new GTOEngine();
const recommendation = engine.getRecommendation(gameState);
```

### 带剥削
```typescript
const opponentTendency = {
  foldToCBet: 0.75,
  aggressionFactor: 1.5,
  // ...
};

const recommendation = engine.getRecommendation(gameState, opponentTendency);
```
