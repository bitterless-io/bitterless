空清单

说明当前来源还没有技能。全局提供打开目录与导入入口；工作区仅发现技能、打开文件及目录；机构显示“暂无机构下发技能”。搜索无结果单独说明。

格式错误

坏 YAML 保留在对应清单并显示错误位置；从 Chat 可用清单排除。修复并保存后自动重新解析，成功后恢复为可用。

离线与未验证

机构同步状态显示“离线 · 授权待验证”。未验证的机构技能不进入可用清单；全局与工作区仍能使用。恢复连接后自动重试。

热重载

仅刷新变动技能，保持所选 Tab 与列表位置。界面区分扫描、可用、错误；正在执行的任务与下一次发送所用版本由功能设计约定。

窄屏与键盘

740px 以下先清单后详情，三个来源始终可见。Tab 聚焦来源组、方向键切换原生 radio；所有实际操作需有可见焦点。此稿中按钮、搜索与筛选仅示意。
